    推理模型：先想一想，再回答

    第一部分 · 大模型本身 · 第 7 篇　|　约 14 分钟　|　3 个小实验

    一句话结论推理模型会在回答前先写一大段草稿（思维链），把难题拆成小步、一步步算、回头检查。道理很朴素：模型每写一个 token 只能做固定量的计算，多写草稿就等于多给它思考时间。2024 年起，人们开始用强化学习，专门把这种「先想再答」的习惯练出来。

    01为什么多写几个字，就能变聪明

    回想第 1 篇：模型每输出一个 token，都要让整串文字从头到尾流过所有层，每一步的计算量是固定的，不会因为题目难就多算一会儿。所以，如果逼它「看完题马上报答案」，它只有一个 token 的计算量来解题。

    可它写下的每个字都会回到上下文里，成为下一步的输入。写出来的中间步骤，就是它的草稿纸：每一步只需要做一点点小计算，难题被摊到了很多个 token 上。Karpathy 的说法是：模型需要用 token 来思考。

    这也解释了上一篇提到的短板：一口气心算多位数乘法很容易错，但让它把过程写出来就可靠得多。

    02思维链：从一句提示开始

    2022.1
    思维链提示（Chain-of-Thought）
    Google 的 Wei 等人发现：在提示里放几道「带解题过程」的例题，模型就会模仿着先写过程再给答案。只用 8 道这样的例题，PaLM 540B 在小学数学应用题测试 GSM8K 上达到了当时最好成绩。这种好处主要在足够大的模型上才出现。
    2022.3
    多想几遍，投票（自洽性）
    Google 的 Wang 等人让模型对同一道题写多条不同的思路，再看哪个答案出现最多。这让 GSM8K 的准确率又提高了 17.9 个百分点。下一节就来玩这个。
    2022.5
    「让我们一步一步地想」
    东京大学等的 Kojima 等人发现，连例题都不用给，只在问题后面加一句 “Let's think step by step”，InstructGPT 在 MultiArith 上的准确率就从 17.7% 升到 78.7%，GSM8K 从 10.4% 升到 40.7%。
    2024.9
    OpenAI o1：把「先想」训练成本能
    不再靠提示词诱导，而是用强化学习训练模型在回答前写很长的内部思维链。OpenAI 发现，训练时的强化学习越多、回答时想得越久，成绩就越好。
    2025.1
    DeepSeek-R1：公开配方
    DeepSeek 公开了论文和模型权重，详细说明了只靠「答案对不对」的奖励，也能练出会反思、会验算的推理模型。

    概率是为演示设的。真实情况是：越大、越强的模型，一口气答对的把握越高；但题越难，分步写的好处越明显。

    03多想几遍再投票

    采样有随机性（第 1 篇的温度），同一道题让模型写好几遍，思路和答案都可能不同。自洽性（self-consistency）的做法是：写 N 遍，取出现最多的答案。OpenAI 公布 o1 的成绩时也用过这招：AIME 2024 数学竞赛题，o1 只答一遍平均做对 74%，答 64 遍取多数能到 83%。

    按二项分布精确计算，取最不利的假设：所有错误答案都一样，所以只有答对的票数过半才算赢。真实中错误答案往往五花八门、互相分票，投票的效果通常更好。

    把 p 拖到 50% 以下试试：投票反而让结果更差。投票只能放大模型「本来就更倾向」的那个答案，把一个大多时候会错的模型变不成对的。这也是为什么提高单次思考的质量（下一节）才是根本。

    04推理模型：用强化学习练出「会想」

    思维链提示是「请它先想」，推理模型则是在后训练里专门训练它想。DeepSeek-R1 的论文把做法讲得很清楚，核心出奇简单：

    1. 找大量答案可以自动判对错的题：数学题（对一下最终答案）、编程题（跑一下测试）。
    2. 让模型对每道题写好几遍，每遍都先在 <think> 标签里写思考过程，再给答案。
    3. 只按两条规则打分：答案对不对、格式对不对。不评价过程写得好不好，也不用人类标注者。
    4. 用强化学习（他们用的是 GRPO：同一题的几遍答案互相比较，比平均好的就加强）更新模型，然后重复。

    结果很惊人。先只用这种强化学习训练基础模型（R1-Zero），AIME 2024 的单次准确率从 15.6% 升到 71.0%，多数投票到 86.7%。没有人教它怎么想，但它的回答自己越写越长，并开始出现回头检查、换思路这些行为。论文里记录了一个「顿悟时刻」（aha moment）：模型在草稿中写下「等等，等等。这是个顿悟时刻……」，然后重新审视自己的解法。

    小实验 ③：只奖励「答对」，会练出什么？玩具模型

    模型做题时有 4 种习惯，每种的答对率和长度是我们设定的。每一轮：同一题做 8 遍，答对得 1 分；比这 8 遍平均分高的习惯被加强，低的被削弱（GRPO 的思路）。注意：奖励里完全没提长度。

    R1-Zero 也有毛病：思考过程不好读，还会中英文混杂。所以正式的 DeepSeek-R1 先用少量写得规范的长思维链示范「热身」，再做强化学习，最后再加上常规的后训练，让它在聊天、写作上也表现正常。

    OpenAI 没有公开 o1 的训练细节，只说它是「用强化学习训练的」，而且训练时的计算和回答时思考的时长都能提升成绩。这是除「把预训练做大」之外的另一条扩展路线。o1 的原始思维链对用户隐藏，只展示模型生成的摘要；DeepSeek-R1 则会显示完整的思考内容。

    05想得越久越好吗？

    • 更慢、更贵：草稿也是 token，要计算、要计费。一个难题可能先想上几千个 token 才开口。所以很多产品让你选「思考强度」，或由系统自动判断要不要深想。
    • 不是什么都有用：OpenAI 的人类偏好评测显示，o1-preview 在数据分析、编程、数学上明显更受欢迎，但在一些纯文字类任务上并不比 GPT-4o 更受欢迎。改写邮件、聊天，用不着先想三分钟。
    • 草稿未必是真实想法：Anthropic 2025 年的研究在题目里偷偷放了「提示」，模型用了提示，却常常不在思维链里承认。平均下来，Claude 3.7 Sonnet 只有 25% 的情况提到了提示，DeepSeek-R1 为 39%。所以思维链能帮我们观察模型，但不能全信。
    • 仍会出错：推理模型减少了计算和逻辑错误，但冷门事实照样可能编（第 5 篇），需要查资料的问题还是要靠 RAG 或工具。
    怎么用：数学、编程、复杂分析、需要多步规划的问题，选推理模型或打开「深度思考」；简单问答、润色、聊天，用普通模型就好，又快又便宜。用推理模型时，把目标和条件说清楚就够了，不必再写「请一步步想」，它本来就会。

    06记住这些就够了

    1. 模型每个 token 的计算量是固定的，写出中间步骤 = 多给它思考的时间。这就是思维链有用的原因。
    2. 推理模型用强化学习，在能自动判对错的题上反复练，只奖励答对，「先拆解、再验算」的习惯和更长的思考就自己长出来了。
    3. 多想、多投票都要花更多计算，而且只对难题划算；思维链也不一定忠实反映模型「真正」怎么想的。
